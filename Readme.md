邓伟川的仓库分支
==============
视觉组
------
在git中使用以下命令推送到本分支：<br>
git push origin `本地分支名`:`远程库分支名`<br>

------
Markdown语法注意：<br>
1.直接回车不能换行,要使用\<br>。<br>
2.显示超链接直接输入它的URL 格式：【要显示的文字】（URL）"悬停显示" 英文双引号哈<br>
3.半角首空格默认忽略，改为全角空格即可 shift+space切换<br>
4.行首使用两个Tab键实现单行文本<br>
5.部分数字高亮用``字符把`文字`包围起来<br>
6.圆点符编写行首使用星号*，用多个Tab可多级表示<br>
7.缩进行首使用>符号（可多个）<br>
8.插入网络图片就用超链接<br>
9.插入代码片段，代码的上一行和下一行用三个` 标记，标记之后要加上编程语言类型<br>
10.在GitHub上可以用Gist写日记<br>
