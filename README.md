# fzsd_robomaster
浮舟湿地战队算法组预备队员仓库

#介绍
此次文件是视觉组第一次任务，用YOLO实现基础的装甲板识别。

#使用
1.安装
在使用前，请确保安装了conda,pytorch.并进行相应环境配置，确保python版本在3.1.0及以上

之后请前往ultralytics官网下载YOLO，完成相应配置
视频默认为提供的demo视频

2.文档
best.pt内为此次训练好的模型；
train_model为此次训练模型所使用的代码
run代码直接执行打开视频进行装甲板的识别
run_camera代码执行打开摄像头的识别
