## 我遇到的困难以及解决办法：（我好像是把readme当技术文档写了）

### 2.1 关节转角速度太低，不足以及时击球

我将5号关节的关节插值变大，这样能加快“抬手”的速度，并且其他关节的step不改变，这样能防止其他位置产生抖动
```c
if (i == 4)  step = 0.8;
else  step = 0.01;
```
### 2.2 机械臂击球部分的杆子太短，打不太到

我延长了一点（）

### 2.3 机械臂在调整完关节插值后产生的轻微抖动

是由于关节插值太大，导致now想要变到set需要反复往返走step，step写小一点可以减小抖动。

## 对于接住打过来的排球

首先要让车“看见”排球的位置（雷达或者摄像头，“实时”测量排球相对位置）
其次要根据排球位置移动的数据来计算推断排球可能的落点
然后驱动底盘移动到相应位置并让机械臂做好接球准备动作
最后根据自己的接球动作组来适时地执行接球动作组，完成接球（）
